💾 Backup & Export Database Web

Mencadangkan seluruh data: siklus menu, master bahan, frekuensi, alergen, sasaran peserta didik, serta semua log harian beserta foto (suhu, kontaminasi silang, alergen, pemorsian, pendinginan). File berformat .json dan bisa dipulihkan kembali di bawah.

Memeriksa riwayat backup...

Saran: lakukan backup seminggu sekali dan wajib di akhir setiap siklus menu. Simpan file di Google Drive / flashdisk, bukan hanya di komputer ini.

📊 Ukuran Data Tersimpan

Untuk memantau kapasitas penyimpanan di server. Foto adalah penyumbang terbesar.

♻️ Pulihkan dari File Backup

Pilih file .json hasil backup di atas untuk mengembalikan data. Sebelum memulihkan, sistem otomatis mengunduh backup pengaman dari data saat ini.

Perhatian: data menu, bahan, frekuensi, alergen, dan sasaran akan diganti dengan isi file. Log harian digabung per tanggal: tanggal yang sama ditimpa, tanggal lain tidak dihapus.
